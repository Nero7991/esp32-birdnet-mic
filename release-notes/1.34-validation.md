# Firmware 1.34 validation — 2026-10-22

- All four builds passed with the pinned Arduino-ESP32 3.3.12 dependencies. App-only files: C3 1,269,760 B, S3 1,182,688 B, C5 1,380,112 B, C6 1,284,000 B. C6 retains 26,720 B in its existing OTA slot.
- C5 also compiled successfully with explicit `PSRAM=disabled`, using a separate build/output directory. The default helper enables C5 PSRAM and respects an explicit setting. Other board build options are unchanged.
- All four partition tables are byte-identical to v1.33. The generated four-board manifest, versioned images, manual OTA copies and C6 compatibility aliases pass the OTA release contract.
- All 59 Python host/regression tests passed, including native DSP, preview and transport tests. Additional discovery/scheduling native tests, Web UI health and thermal UI tests passed. The S3 browser test passed against both source and embedded UI, including Sense I2S controls, AtomS3U format locking, failed saves and pending drafts.
- New simulated tests run the actual ring allocation/deletion and producer-start functions: PSRAM availability/allocation failure, internal fallback, internal-memory/fragmentation rejection, task-start failure and 50 repeated capture starts. Preview tests cover external storage ownership, wrapping, overflow and rejection of resizing after first use.
- Sense native tests exercise both I2S formats, PDM routing, failed-restart rollback, AtomS3U restrictions and restoration of every stored board value with each valid microphone format. The Sense board profile persists when using external I2S.
- Physical C6 I2S OTA to v1.34 succeeded. All 23 selected configuration/identity fields across status, audio, performance and thermal APIs were preserved. The served HTML equals the decompressed embedded payload; the generator verifies it against the source.
- Physical C6 RTSP/TCP reception produced 720,512 nonzero 48 kHz mono samples (about 15 s). Browser listening produced a valid 48 kHz mono WAV stream with 96,000 nonzero PCM samples. UDP reception on the temporarily enabled BirdNET-Pi Stream 2 produced 480,512 nonzero samples (about 10 s); Stream 2 was restored OFF and checked against the original configuration.
- After those checks, C6 reported a 65,536 B internal RTSP ring, a 16,384 B listening queue and zero I2S errors, DMA overruns and ring drops. The existing Stream 1 remained enabled and streaming.

Contributor evidence is distinct from these maintainer checks: AtomS3U was tested with BirdNET-Go on v1.33, and the C5 PSRAM patch on v1.33 ran for 9.2 hours with IM73D122. Maintainer physical testing of the final v1.34 C5/PSRAM and Sense/AtomS3U hardware remains pending. No antenna changes are part of this release.
