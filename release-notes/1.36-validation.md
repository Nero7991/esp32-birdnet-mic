# Firmware 1.36 validation — 2026-10-25

## Change

C5 with PSRAM uses the existing 64 KiB C5 Wi-Fi allowance when recreating its external audio ring. Producer-stack, allocation-overhead and largest-block checks remain. Other targets and the C5 internal fallback retain their existing rules. No adaptive noise filter is included.

The contributor patch includes a hardware failure log and reports successful gain changes after applying the fix on C5 + IM73D122. Maintainer validation below uses host simulation and a physical C6; it does not replace physical C5 qualification.

## Checks

- All four pinned Arduino-ESP32 builds passed: C3, S3, C5 with PSRAM and C6. An additional C5 PSRAM-disabled build passed.
- The new C5 lifecycle regression fails on the original allocation functions and passes with the patch. Exact values from the failure log and the 72,704-byte minimum internal reserve boundary were checked separately. Lifecycle tests use AddressSanitizer and UBSan.
- Python suite: 83 tests passed with one skipped (including download statistics and nginx bridge routing).
- Main Web UI health/MQTT and thermal UI checks passed. Download-statistics browser tests passed: totals, breakdowns, filters, older versions, desktop/mobile themes, OTA navigation, unavailable/retry handling and no Umami download events.
- OTA release contract passed for 1.36. Frozen v1.35 bridge images and partition files remain unchanged.
- Physical XIAO ESP32-C6 updated directly from 1.35 to the local verified 1.36 image through manual HTTP OTA. Its prepared layout remains ready with 2,031,616-byte capacity; 35 selected audio/thermal/network settings matched after reboot.
- Capture restarted, RTSP TCP reception (8 seconds) and simultaneous browser WAV reception (6 seconds) succeeded. Follow-up status showed zero I2S errors and zero DMA overruns. UDP was not validated: requesting it on the configured TCP stream was rejected by ffmpeg as a transport mismatch; stream configuration was not changed.

## Distribution

Release publishing verifies all 37 GitHub/public assets, board-specific versioned files, C6 aliases, the current feed and permanent legacy v1.35 bridge. Website download-statistics changes are included with user approval; existing collector state is retained by deployment.
