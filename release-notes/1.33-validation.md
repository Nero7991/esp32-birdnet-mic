# Firmware 1.33 validation — 2026-10-21

- All four builds passed with pinned Arduino-ESP32 dependencies. App-only image sizes: C3 1,268,752 B, S3 1,181,792 B, C5 1,373,856 B, C6 1,283,040 B. C6 retains 27,680 B in its existing OTA slot.
- All partition tables remain unchanged. Board-specific images, versioned files, manual OTA copies and compatibility aliases pass the OTA contract; each image contains the current embedded UI.
- All 55 host/regression tests passed. Source and embedded settings browser tests, thermal UI tests and Web UI health checks passed.
- Simulations cover OTA pause/failure recovery, sensor read failures/range changes, thermal persistence/migration, exact cooling boundaries, emergency/repeated trips and failed capture restarts. Explicit protection OFF permits manual acknowledgement despite missing/invalid sensor samples and safety blocks; OFF alone never resumes streaming. Re-enabling protection restores the cooling requirement, and active OTA still blocks manual restoration.
- Physical C6 I2S OTA passed with all 37 checked configuration/identity fields and the performance-settings group preserved. The served UI matches the embedded payload.
- On the C6, temporarily lowering the configured limit to 30 °C triggered the real emergency shutdown at normal chip temperature, without heating the device. Capture stopped and an early acknowledgement with protection ON was rejected.
- Using the real Web UI to switch protection OFF left capture and RTSP paused, while enabling acknowledgement immediately. Clicking the acknowledgement button cleared the saved block and restored capture/RTSP in 414 ms, without waiting for cooling or rebooting. The original 85 °C limit, protection ON and other settings were restored.

Physical overheating qualification and PDM runtime testing of this release on the other boards remain unverified.
