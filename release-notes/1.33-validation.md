# Firmware 1.33 validation — 2026-10-21

- All four builds passed with the pinned Arduino-ESP32 dependencies. App-only image sizes: C3 1,268,656 B; S3 1,181,712 B; C5 1,373,808 B; C6 1,282,928 B. C6 retains 27,792 B in its existing OTA slot.
- All four partition tables are byte-identical to v1.32. Each image contains the current embedded Web UI; board-specific images, versioned files, manual OTA copies and compatibility aliases pass the OTA contract.
- 55 regression tests passed, plus native discovery/time-zone tests, thermal/browser-audio UI tests, source/embedded settings browser tests, OTA browser tests and responsive UI checks.
- Simulations exercise the production OTA and thermal functions: capture stops before I2S/PDM resources are released; failed updates restore capture while retaining thermal/schedule restrictions; successful updates remain paused until reboot; failed sensor reads cannot supply a valid hot reading; measurement ranges change when needed. Cooling tests cover the exact ten-degree/five-minute boundary, invalid/stale samples, reboot, saved-state migration, emergency/repeated shutdowns and capture-restart failures. A migrated manual/emergency latch can be acknowledged after valid cooling.
- Physical XIAO ESP32-C6 with I2S: manual HTTP OTA from v1.31 to v1.33 succeeded. All 37 selected settings and the performance-settings group were retained; the served UI matches the embedded payload. No thermal latch or sensor fault appeared.
- On v1.33, a deliberately invalid 1,024-byte OTA upload was rejected without reboot; capture and RTSP recovered. A subsequent valid v1.33 upload succeeded and retained settings. RTSP/TCP reception passed for 15 seconds after failure and again after the successful retry.
- After the retry, browser playback produced 704 nonzero PCM blocks at 48 kHz. No new I2S read errors or DMA overruns occurred. Chip temperature was 45.8 °C; the saved 85 °C shutdown limit correctly exposes a 75 °C cooling target.

Thermal trips and cooling were simulated; physical overheating qualification and PDM runtime testing of this release on the other boards remain unverified.
